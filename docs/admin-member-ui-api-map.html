01

어드민 로그인

기존 관리자 토큰을 그대로 쓴다. 회원 어드민 전용 로그인은 없다.

POST /admin/auth/login
02

회원 목록 진입

요약 카드와 첫 페이지를 나란히 부른다. 요약은 필터와 무관하므로 이후 재호출하지 않는다.

GET /admin/member/summary GET /admin/member?page=1&count=10
03

검색

한 칸에 이메일·닉네임·이름·전화번호 중 무엇을 넣어도 같은 파라미터로 나간다.

GET /admin/member?search=chen
04

상세 진입

계정·프로필·체형·연동·동의를 한 번에 받는다. 이 시점에 활동 탭은 부르지 않는다.

GET /admin/member/1042
05

활동 탭을 연다

연 탭만 한 번씩. 주문 → 장바구니 순으로 여는 게 대부분이다.

GET /admin/member/1042/order GET /admin/member/1042/cart
06

수신 거부 요청 처리

204 라 본문이 없다. 동의 일시를 화면에 다시 그리려면 상세를 한 번 더 부른다.

PATCH /admin/member/1042/agreement GET /admin/member/1042
07

강제 탈퇴

202 를 받으면 상세를 닫고 목록을 다시 조회한다. 그 회원은 기본 목록에서 사라진다.

DELETE /admin/member/1042 GET /admin/member?page=1

정해진 것 · 남은 것

시안 검토에서 세 가지가 확정됐고, 그대로 구현했다.

확정개인정보는 평문

주소·생년월일·전화번호를 마스킹 없이 내려준다. 열람 감사 로그도 넣지 않았다.

확정CSV 내보내기 제외

개인정보 대량 반출이라 이번 스코프에서 뺐다. 신규 엔드포인트는 8개다.

확정“관리자 계정” 라벨

/admin/user 의 Swagger 요약을 “관리자 계정 목록”으로 바꿨다. 프론트 메뉴 라벨도 같이 바꿔야 한다.

구현하면서 같이 고친 것

Swagger 에 /admin/member 가 아예 없었다

main.ts 의 docsInclude 에 AdminMemberModule 이 빠져 있어, 기존 강제 탈퇴 API 도 문서에 뜨지 않고 있었다. 추가했다 — 이제 9개 전부 AdminMember 태그로 보인다.

테스트 환경 PORT 고정

env/test.ts 의 PORT: 3001 이 하드코딩이라 포트가 물려 있으면 띄울 수 없었다. local.ts 와 같게 env 로 덮을 수 있도록 바꿨다.

이번 스코프에 넣지 않은 것

다음비밀번호 초기화 · 계정 정지

user 에 정지 상태 컬럼이 없다. 넣으려면 엔티티 변경이 먼저다. 지금은 탈퇴만 가능하다.

다음회원별 메모 · CS 이력

저장할 테이블이 없다. 새 엔티티(user_admin_memo)가 필요해 별도 건으로 본다.

다음주문 상태 변경 · 환불
