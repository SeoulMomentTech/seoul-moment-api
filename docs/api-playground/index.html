설정 · 로그인

여기서 토큰을 받아두면 다른 페이지에서 그대로 씁니다.

GET 서버 연결 확인 /health

Base 주소가 맞는지, 서버가 떠 있는지 먼저 봅니다.

POST 사용자 회원가입 + 로그인 /user/auth/signup · /user/auth/login

로그인 응답의 data.token 이 ONE_TIME_TOKEN 입니다. 이 값을 저장해 Authorization: Bearer 로 씁니다.

사용자 프로필 — 기본 배송지

주문에서 useDefaultShipping: true 를 쓰려면 프로필 주소와 전화번호가 채워져 있어야 합니다. 비어 있으면 주문 생성이 400 으로 떨어집니다.

전화번호는 인증 플로우가 따로 있어 여기서 넣지 못합니다. 비어 있으면 DB 에서 직접 채우세요 — UPDATE "user" SET phone='+886912345678' WHERE email='...';

POST 관리자 로그인 /admin/auth/*

배송비 정책 페이지에서만 필요합니다. 가입 → 로그인 → one-time-token 3단계를 한 번에 처리합니다.
