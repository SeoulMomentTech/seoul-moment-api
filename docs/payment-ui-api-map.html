왼쪽은 실제로 붙을 화면, 오른쪽은 그 화면의 각 요소가 부르는 API다. 번호가 좌우를 잇는다 — 어느 쪽이든 올려두면 짝이 같이 켜진다.

ECPay · LINE Pay 전자발표 5종 편의점 픽업 (7-ELEVEN · 全家 · 萊爾富) DEV 배포 2026-11-04

인증

주문·결제·발표 확인은 회원 Authorization: Bearer. 편의점 지도·매장 조회·결제 결과는 토큰 없이 된다 — LINE 밖 외부 브라우저에는 로그인이 없기 때문이다.

응답 봉투

성공은 { result, data }. 이 문서의 → 는 data 안쪽만 적었다. 실패는 { message, code, traceId, data? }.

금액

통화는 NT$, 전부 정수다. 배송비·합계는 서버 값을 그대로 쓴다. 기본 60 · 외섬 100 · 1,150 이상 무료.

필드 표기

key 필수 · key? 선택(응답에선 null 가능) · key* 조건부 필수(조건은 카드 본문) · // ① // ② 택1. 정의하지 않은 키를 보내면 400 이다.

변경 표기

기준은 cart-order-frontend-guide.html(주문 1차). new 새 API · updated 필드가 늘어난 API. 라벨이 없으면 예전 그대로다.

LINE 안에서 외부로 넘어온 경우 LINE 쪽 원래 화면이 이미 폴링으로 완료로 바뀌어 있다(06). "LINE 으로 돌아가기" 는 LIFF URL 을 열기만 하면 된다. 주문 상세는 로그인한 브라우저에서만 열린다.

프론트 결과 페이지가 아직 없으면 서버가 그린 간단한 결과 화면(번체 중문)이 대신 뜬다 — 지금 DEV 가 그렇다. 프론트 주소(STOREFRONT_BASE_URL)를 알려주면 서버 설정에 넣고, 그때부터 {프론트}/payment/result?h= 로 303 리다이렉트된다.
