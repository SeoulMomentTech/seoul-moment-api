LINE 로그인 플로우 테스트

seoul-moment-api 의 /user/auth/line/* 3단계 플로우(로그인 · 연결확인 · 신규가입)를 브라우저에서 직접 검증하는 도구입니다. LINE 공식 LIFF SDK로 로그인해 id_token을 프론트에서 직접 받습니다(서버 교환 불필요). scope는 openid profile이라 이메일 권한 심사 전에도 동작합니다(이메일이 없으면 서버가 placeholder로 가입).

설정

⚠️ LINE Developers Console → 해당 LINE Login 채널 → LIFF 탭에서 LIFF 앱을 추가하고, Endpoint URL을 이 페이지 주소()로, Scope는 openid + profile로 설정하세요. 그 후 발급된 LIFF ID를 위에 입력합니다. (개발 중에는 endpoint로 http://localhost도 허용됩니다.)
